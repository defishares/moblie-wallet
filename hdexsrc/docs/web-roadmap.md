# DefiShares Web App 开发路线图

## 目标

新增独立 Web UI，并与 React Native 应用共享网络配置、领域类型、金额/行情规则和链上访问契约。移动端继续独立发布，Web 端不复制业务规则、不降低私钥安全等级。

## 验收原则

1. 每个阶段都必须通过类型检查、测试和生产构建。
2. 链上余额、订单、行情和配置始终以区块链节点或 Gateway 返回为准。
3. Web 与移动端使用相同的交易对方向、资产精度和金额换算规则。
4. 私钥不得以明文写入 Local Storage、IndexedDB、日志或网络请求。
5. 交易广播必须经过 RN 行为一致性、二次确认和安全验证；未完成发布验收前不得作为正式生产能力。

## 推荐发布闸门

- **Alpha**：阶段 1、2 完成，只读内测。
- **Beta**：阶段 3 完成，转账签名与广播仅在 Testnet 验收环境开放。
- **Release Candidate**：阶段 4、5 完成，Testnet 全量验收。
- **Production**：阶段 6 完成并通过安全评审。

## 当前剩余闸门

1. **Testnet 端到端**：仓库当前的 `TESTNET_CONFIG` 与 RN 保持一致，但没有独立的 Testnet WebSocket 链 ID/节点和专用测试账户凭据；不能把主网节点当作测试网执行写入。部署方提供真实 Testnet 节点、链 ID 和测试账户后，按 `docs/web-release-runbook.md` 执行全量广播验收。
